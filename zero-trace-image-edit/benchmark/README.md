## 评测方法（见 score.py）

- 框外保真度 = 改动点 mask 外区域，原图与改后图像素一致率（阈值：单通道差>8 计为差异）
- 残影率 = 改动点 mask 内区域，改后图与原图的平均像素差 / 255（仅去物体/去水印任务）
- 零痕分评级：**A+** = 框外保真≥99.5% 且 残影率<5%；**A** = 框外≥99% 且 残影<10%；其余为 B/C

## 诚实承诺

任何技能宣称零痕，都按同一把尺量框外保真度；我们公开自己的测试图与结果，欢迎第三方复测。
