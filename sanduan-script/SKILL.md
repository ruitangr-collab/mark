# 三段式结构脚本创作法

## 核心理念

**不卖避险，卖抢滩；不卖下注，卖先机。**

你不是在帮客户"降低风险"，你是在帮客户"抢先占位"。
你不是在让客户"押注"，你是在让客户"锁定窗口期"。

所有措辞往"进攻"方向走，放弃"防守"语言。

---

## 三段式标准结构

### ① 锁定/诊断 —— 低门槛、高价值的第一交付物

一句话：用最少的投入帮客户看清最关键的问题。

**格式：**
- 一个具体的动作 + 一个具体的产出物
- 必须数据驱动，不能空泛
- 让客户觉得"花5分钟就能搞明白"

**示例句式：**
- 「用1页纸理清「你的品类 × 最有戏的国家」」
- 「锁定「抢位国家」——用数据告诉你窗口期在哪」
- 「一张表看懂你的品类在非洲的竞争格局」

### ② 路径/打法 —— 可执行的路线图

一句话：给客户一条明确的、可跟着做的路径。

**格式：**
- 一套有时间/步骤概念的执行方案
- 必须具体到"怎么做"，不能是抽象建议
- 强调整体设计的系统感（"从我到那"的全程规划）

**示例句式：**
- 「搭一套「30天非洲冷启动路线图」—— 从选品验证到本地触达」
- 「拆解「进场打法」—— 一套能直接执行的清单」
- 「给你一张「3周落地作战地图」」

### ③ 避坑/风控 —— 实战可见的护城河

一句话：展示你对这个领域的深度认知，建立信任。

**格式：**
- 必须是具体的、接地气的坑，不能是泛泛的"有风险"
- 暗示"我踩过/见过这些坑，你可以不用踩"
- 把风控包装在"执行"里，而不是单独拿出来吓人

**示例句式：**
- 「设计一份「避开大坑的实地验证清单」—— 去了当地看什么、问什么、怎么判断真伪」
- 「避开「致命暗坑」—— 哪些是政治坑、供应链坑、本地人坑」
- 「一份「防亏钱自查表」—— 进场前先排除80%的坑」

## 两种语气风格

### 风格A：实战顾问版（适合微信私聊/朋友圈）

| 要素 | 写法 |
|---|---|
| 语气 | 专业、靠谱、帮老板省事儿 |
| 开头 | 陈述式，展现你在帮他节省时间 |
| 内容 | 理性、有条理，每个点解释清楚"为什么" |
| 结尾/CTA | 低姿态引导：「你可以直接告诉我你的阶段... 我帮你选最省力的路径」 |
| 核心策略 | 表现得像"你可以白嫖一个免费咨询" |

### 风格B：销售强攻版（适合海报/引流/投流）

| 要素 | 写法 |
|---|---|
| 语气 | 紧迫、犀利、直击痛点 |
| 开头 | 制造紧迫感：「不是没机会，是你慢一步就没位子了」 |
| 内容 | 干脆、利落，每句话都是钩子 |
| 结尾/CTA | 指令式：「直接甩我这三个信息」 |
| 核心策略 | 表现得像"窗口期马上关闭，你现在不动就晚了" |

---

## 黄金组合要素

1. **开头Hook**：一个让目标读者"这说的是我"的开场
2. **三段式主体**：①→②→③ 结构，每段必须有标题+解释
3. **强CTA结尾**：要求客户提供2-3个具体信息作为入场券
4. **降低预期收尾**：「我帮你判断值不值得」/「选最省力的路径」—— 显得客观中立，反而更容易成交

## 应用示例

### 通用模板（填空即用）

```
[开头Hook - 点明目标人群痛点]

我帮你用3步理清：

① [锁定] [具体产出物]
[一句话解释为什么这个有用]

② [路径] [可执行方案名]
[一句话解释怎么做]

③ [避坑] [防坑清单名]
[一句话解释为什么你信得过]

[CTA] 直接告诉我：[3个具体问题]
我帮你判断：[给客户的承诺]
```

### 出海非洲场景复用

| 原始三段式 | 出海非洲版本 |
|---|---|
| ① 1页纸理清品类×社群定位 | ① 1页纸理清品类×最有戏的国家 |
| ② 7天清单完成基础布局 | ② 30天非洲冷启动路线图 |
| ③ 1次导流话术设计 | ③ 避开大坑的实地验证清单 |

## 记忆点

- **始终攻，不要守** —— "抢滩" > "避险"，"先机" > "下注"，"窗口期" > "稳一点"
- **每一段都要可执行** —— 不能只有一个概念名，要加一句具体的"这是什么"
- **三段递进**：先看清 → 再会做 → 最后少吃亏
- **CTA要具体** —— 让客户填的信息越具体，筛选越精准
- **结尾别吹牛** —— 说"帮你判断"比"保证成交"高级十倍
