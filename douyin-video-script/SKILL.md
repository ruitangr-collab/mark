# 抖音短视频脚本生成技能

## 概述

本技能将策略文档中的选题转化为可直接拍摄的抖音分镜脚本。输入是一个包含系列规划、选题列表、钩子类型的策略 JSON，输出是一份完整的、带时间戳、文案、画面说明和发布策略的脚本文件。

触发条件：
- 用户提供了策略 JSON 文件路径，并要求写某个选题的脚本
- 用户说"写脚本""生成脚本""帮我做视频脚本"
- 用户指定了策略文档中的某个 `id`（如 `005`）要求生成脚本

---

## 工作流程

### Step 1：读取并解析策略文档

用 `Read` 工具读取用户提供的策略 JSON 文件，理解以下结构：

```json
{
  "series": [
    {
      "name": "系列名称",
      "freq": "发布频率",
      "desc": "系列说明",
      "topics": [
        {
          "id": "001",
          "title": "选题标题",
          "hook_type": "钩子类型"
        }
      ]
    }
  ]
}
```

记录关键信息：
- 共有几个系列，每个系列的定位
- 目标选题的 `id`、`title`、`hook_type`

---

### Step 2：确定钩子类型对应的开场策略

策略 JSON 中的 `hook_type` 对应以下四种开场方式，脚本的「黄金 3 秒」必须匹配对应类型：

| hook_type 值 | 中文名 | 开场方式 | 适用场景 |
|---------------|---------|---------|---------|
| `成本反差钩子A` | 成本反差 | 亮出具体数字（国内高价 vs 非洲低价），制造冲击 | 数字型选题（土地、人工、房租） |
| `风险前置钩子B` | 风险前置 | 直接说出最坏结果，用恐惧/警惕留住用户 | 避坑、预警类选题 |
| `实操诱惑钩子C` | 实操诱惑 | 承诺"公开账本/全流程/内部数据"，激发好奇心 | 经验分享、账本公开类 |
| `争议讨论钩子D` | 争议讨论 | 抛出一个有争议的观点，引诱评论区辩论 | 管理、文化冲突类选题 |

#### 时长与节奏规则

| 内容类型 | 建议时长 | 节奏要点 |
|---------|---------|---------|
| 数字反差类 | 35–45s | 前 10s 密集抛数字 |
| 经验分享类 | 45–55s | 情绪曲线要完整 |
| 避坑预警类 | 30–40s | 开门见山，不铺垫 |
| 实地探店类 | 50–60s | 一镜到底感 |

#### 文案写作规则

每条文案必须满足：
1. **不超过 30 字**（字幕屏显限制）
2. **口语化**，不用书面语
3. **有情绪**，不用陈述句平铺
4. **关键数字用大字单独弹出**，不在字幕里堆砌

### Step 4：去 AI 味处理

脚本初稿完成后，**必须**调用 `humanizer` 技能（路径：`/Users/goterra/.workbuddy/plugins/marketplaces/experts/plugins/douyin-strategist/skills/humanizer`）对脚本中的所有口播文案进行去 AI 味处理。

具体操作：
1. 提取脚本中所有「文案（字幕）」列的文字内容
2. 将这些文字作为 humanizer 的输入
3. humanizer 会输出去 AI 味后的版本
4. 用 humanizer 的输出**替换**脚本中对应的文案内容

去 AI 味的核心原则（humanizer 自动处理，但生成时需检查）：
- 不用"首先、其次、此外"等 AI 高频词
- 不用"值得一提的是""总的来说"等套话
- 不用三个及以上排比句
- 不用 Em dash（—）连接句子
- 句子长短交错，不全部是完整句
- 允许口语化的不完整句、语气词

---

### Step 5：写入文件并交付

1. 将完整脚本写入工作区文件，命名格式：`douyin_script_<选题id>.md`（如 `douyin_script_005.md`）
2. 用 `deliver_attachments` 工具将脚本文件交付给用户
3. 在交付时附上一段简短说明：这个脚本的设计逻辑、预期数据、以及接下来要做的动作

## 质量标准

生成的脚本必须满足以下标准，否则需要迭代：

| 检查项 | 标准 |
|-------|------|
| 钩子是否在 3 秒内出现 | 必须 |
| 每 5–8 秒是否有新信息点 | 必须 |
| 文案是否全部口语化（去 AI 味后） | 必须 |
| 是否有明确的评论区引导 | 必须 |
| 是否有发布策略 | 必须 |
| 时长是否控制在目标范围内 | ±5s 以内 |
| 字幕是否全部不超过 30 字 | 必须 |

---

## 注意事项

- **策略 JSON 是真相来源**：脚本的选题标题、钩子类型、系列归属，必须以策略 JSON 为准，不要自行发挥
- **真实感优先于精致感**：拍摄建议里要明确告诉用户"用手机拍就行，不要过度美化"
- **字幕是核心**：抖音 30% 的用户静音观看，字幕决定了信息传递是否完整
- **每个系列的第一个脚本要特别用心**：它决定了整个系列的基调，后续脚本可以复用其风格
